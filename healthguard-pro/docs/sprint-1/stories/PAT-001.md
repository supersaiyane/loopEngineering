## User Story

> **As a** clinician at a hospital network,  
> **I want to** look up, create, and update patient records in HealthGuard Pro,  
> **So that** I can associate vitals and sepsis risk scores with the correct patient.

---

## Acceptance Criteria

- [ ] `POST /v1/patients` creates a patient record scoped to `tenant_id`
- [ ] `GET /v1/patients/:id` returns patient by ID — 404 if patient belongs to a different tenant
- [ ] `GET /v1/patients` lists patients for the authenticated tenant only
- [ ] `PUT /v1/patients/:id` updates patient — 403 if cross-tenant access attempted
- [ ] `DELETE /v1/patients/:id` soft-deletes (sets `deleted_at`) — HIPAA records are never hard-deleted
- [ ] PII fields (`first_name`, `last_name`, `date_of_birth`, `mrn`) stored encrypted with `pgp_sym_encrypt` (pgcrypto)
- [ ] MRN lookup always requires `tenant_id` in query (no MRN-only index exists)
- [ ] All patient record access written to `audit_log` with actor, action, resource_id
- [ ] Cross-tenant denial E2E: authenticated as Hospital A, attempt to GET Hospital B patient → 403
- [ ] Required role: NURSE or higher (no GUEST access)

---

## Data Model

```sql
-- From docs/schema/postgres.sql
CREATE TABLE patients (
    id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id       UUID NOT NULL REFERENCES tenants(id),   -- [TENANT-SCOPED]
    mrn             TEXT NOT NULL,                           -- encrypted [GDPR-ERASABLE]
    first_name      TEXT NOT NULL,                           -- encrypted [PII]
    last_name       TEXT NOT NULL,                           -- encrypted [PII]
    date_of_birth   DATE,                                    -- encrypted [PII]
    sex             VARCHAR(10),
    admitted_at     TIMESTAMPTZ,
    discharge_at    TIMESTAMPTZ,
    ward            VARCHAR(50),
    is_active       BOOLEAN NOT NULL DEFAULT true,
    created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    deleted_at      TIMESTAMPTZ,                             -- soft delete
    UNIQUE(tenant_id, mrn)                                   -- MRN unique per tenant, not global
);
```

## Technical Notes

**No new dependencies.**  
**E2E scope:** cross-tenant denial test is mandatory (`e2e-required` label).  
**pgcrypto:** symmetric encryption key per-tenant stored in AWS Secrets Manager. Sprint 1 uses a single test key; per-tenant rotation is Sprint 2.
