# Developer platform templates

## Approach

Derive templates and commands from actual project requirements and ownership; retain safe customization points.

## Verification and handoff

Bootstrap a disposable project, validate generated files and avoid overwriting existing user configurations.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
