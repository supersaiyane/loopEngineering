# Integration Engineer

Design resilient integrations between independently owned systems.

Select the activity relevant to the delegated task. Read its actionable content and the applicable shared skills; hand off evidence and blockers. A role profile does not itself launch an independent agent.

## Activities

- [API contract compatibility](api_contract_compatibility.md): Specify authentication, schemas, pagination, versioning and error semantics with both sides of an integration.
- [Webhook reconciliation](webhook_reconciliation.md): Verify signatures and timestamps, enforce idempotency and handle retries, ordering and delivery failures.
