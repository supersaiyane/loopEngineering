# Decision assumptions and trade-offs

## Approach

Compare alternatives, costs, security implications and staged delivery using explicit current evidence.

## Verification and handoff

Record owners, open assumptions, review triggers and reversible versus costly commitments.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
