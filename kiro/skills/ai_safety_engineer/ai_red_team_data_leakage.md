# AI red teaming and data leakage

## Approach

Define permitted data flows, abuse cases and harm severity with security and system owners.

## Verification and handoff

Use approved synthetic cases, assess output leakage and escalation paths, and document limitations and mitigations.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
