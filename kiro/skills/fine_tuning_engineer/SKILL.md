# Fine Tuning Engineer

Assess and execute model adaptation with reproducible data and evaluation.

Select the activity relevant to the delegated task. Read its actionable content and the applicable shared skills; hand off evidence and blockers. A role profile does not itself launch an independent agent.

## Activities

- [Fine-tuning data preparation](fine_tuning_data_preparation.md): Compare prompting and retrieval baselines before training; document data rights, quality, deduplication and splits.
- [Fine-tuning evaluation](fine_tuning_evaluation.md): Evaluate candidates against the same held-out tasks, safety cases, latency and cost baseline.
