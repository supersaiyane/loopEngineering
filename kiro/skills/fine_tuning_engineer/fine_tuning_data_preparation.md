# Fine-tuning data preparation

## Approach

Compare prompting and retrieval baselines before training; document data rights, quality, deduplication and splits.

## Verification and handoff

Prevent train/evaluation leakage and record provenance and sensitive-data handling.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
