# Agent handoff evidence

## Approach

Record actual role invocation, inputs, selected skill paths, outputs, verification and blockers using host evidence where available.

## Verification and handoff

Distinguish self-reports and hashes from observed reads; identify missing evidence and avoid attributing wait time as effort.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
