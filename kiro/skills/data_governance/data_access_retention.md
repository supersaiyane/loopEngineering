# Data access and retention

## Approach

Classify fields and purposes, map authorized access and retention requirements, and document deletion propagation.

## Verification and handoff

Verify access and downstream deletion with authorized test data; consult the actual policy and qualified counsel when needed.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
