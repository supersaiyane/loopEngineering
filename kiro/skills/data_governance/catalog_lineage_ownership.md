# Catalog and lineage

## Approach

Record dataset meaning, owner, upstream sources, downstream consumers, refresh policy and versioned interfaces.

## Verification and handoff

Trace changes to affected consumers and identify missing or uncertain lineage explicitly.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
