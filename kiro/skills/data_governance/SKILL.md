# Data Governance

Manage ownership, lineage, classification and access for data assets.

Select the activity relevant to the delegated task. Read its actionable content and the applicable shared skills; hand off evidence and blockers. A role profile does not itself launch an independent agent.

## Activities

- [Catalog and lineage](catalog_lineage_ownership.md): Record dataset meaning, owner, upstream sources, downstream consumers, refresh policy and versioned interfaces.
- [Data access and retention](data_access_retention.md): Classify fields and purposes, map authorized access and retention requirements, and document deletion propagation.
