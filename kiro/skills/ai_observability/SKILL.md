# Ai Observability

Design evidence-based AI and agent monitoring without oversharing sensitive data.

Select the activity relevant to the delegated task. Read its actionable content and the applicable shared skills; hand off evidence and blockers. A role profile does not itself launch an independent agent.

## Activities

- [AI trace instrumentation](ai_trace_instrumentation.md): Capture supported operation, model, duration, outcome and correlation identifiers across agent and tool calls.
- [AI usage and cost accounting](ai_usage_cost_accounting.md): Use provider-reported input, output and cache measurements where available and keep estimated and billed values distinct.
