# AI usage and cost accounting

## Approach

Use provider-reported input, output and cache measurements where available and keep estimated and billed values distinct.

## Verification and handoff

Record scope, attribution and missing sessions; never treat context occupancy as total token consumption.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
