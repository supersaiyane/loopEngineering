# Delivery supply-chain evidence

## Approach

Inventory declared manifests, build artifacts and images; preserve scanner versions, coverage and SBOM provenance.

## Verification and handoff

Run actual builds, image and secret scans where available; block unknown coverage and retain failure artifacts.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
