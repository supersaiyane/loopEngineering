# Tenant migration parity

## Approach

Define migration authority, engine compatibility, per-tenant ordering, backup and failure handling.

## Verification and handoff

Verify fresh upgrade, supported rollback/re-upgrade, catalog parity and partial failures on disposable matching databases.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
