# Age-appropriate AI tutor evaluation

Define the intended age range, learning objectives, allowed assistance and
human-review responsibilities with qualified educators. Build a consented or
synthetic evaluation set covering correct answers, misconceptions, requests for
direct answers, off-topic or unsafe prompts, and provider failures.

Measure factual correctness, age-appropriate language, useful hints, privacy,
refusal and escalation behavior against reviewed examples. Check teacher
approval before generated content is published where required. Record model,
prompt, dataset version, sample size, failures, cost and uncertainty. An LLM
judge is a supplementary measurement, not proof of child safety or learning.
