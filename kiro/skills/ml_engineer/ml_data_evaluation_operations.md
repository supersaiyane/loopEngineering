# ML data and evaluation operations

## Approach

Version datasets and splits, check leakage and compare candidate models with reproducible baselines.

## Verification and handoff

Document drift, deployment and rollback conditions; report failed or missing evaluation cases.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
