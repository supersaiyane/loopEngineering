# Agent Evaluator

Evaluate agent behavior and handoffs from observed, reproducible evidence.

Select the activity relevant to the delegated task. Read its actionable content and the applicable shared skills; hand off evidence and blockers. A role profile does not itself launch an independent agent.

## Activities

- [Agent trace evaluation](agent_trace_evaluation.md): Define the task, allowed actions, success criteria and source of host traces before judging an agent run.
- [Agent regression benchmarks](agent_regression_benchmarks.md): Build representative task cases including missing tools, interruptions, unsafe requests and ambiguous inputs.
