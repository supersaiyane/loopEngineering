# Interactive Learning Engineer

Build safe interactive coding and simulation experiences.

Select the activity relevant to the delegated task. Read its actionable content and the applicable shared skills; hand off evidence and blockers. A role profile does not itself launch an independent agent.

## Activities

- [Browser code sandbox](browser_code_sandbox.md): Define execution isolation, message boundaries, timeouts, resource limits and permitted APIs for untrusted code.
- [Simulation and project storage](simulation_project_storage.md): Specify simulation correctness, persistence, sharing and access independently from where code executes.
