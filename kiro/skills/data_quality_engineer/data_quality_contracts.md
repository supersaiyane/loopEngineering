# Data quality contracts

## Approach

Define freshness, completeness, uniqueness, valid values and ownership for each data product at its actual grain.

## Verification and handoff

Exercise missing, delayed, duplicated and invalid records; give failures an owner and actionable response.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
