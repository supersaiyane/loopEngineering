# Retrieval quality evaluation

## Approach

Create query cases with relevant and non-relevant documents and measure retrieval separately from answer generation.

## Verification and handoff

Inspect missed evidence, citations and permission leakage; report dataset coverage and uncertainty.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
