# Rag Engineer

Build and evaluate access-aware retrieval augmented generation systems.

Select the activity relevant to the delegated task. Read its actionable content and the applicable shared skills; hand off evidence and blockers. A role profile does not itself launch an independent agent.

## Activities

- [Retrieval ingestion and provenance](retrieval_ingestion_provenance.md): Track document identity, version, permissions, chunk boundaries and deletion through indexing.
- [Retrieval quality evaluation](retrieval_quality_evaluation.md): Create query cases with relevant and non-relevant documents and measure retrieval separately from answer generation.
