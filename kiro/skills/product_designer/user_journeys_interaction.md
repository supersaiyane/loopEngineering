# User journeys and interaction

## Approach

Map users, goals, entry points, states and failure paths before specifying screens.

## Verification and handoff

Review the journey against actual requirements, accessibility and usable recovery rather than screen count.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
