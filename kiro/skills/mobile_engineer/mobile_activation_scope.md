# Mobile activation and offline risk

## Approach

Select native development only when the project requires it; specify offline conflicts, permissions and synchronization.

## Verification and handoff

Test device and network failure cases and avoid treating a responsive web app as a native app.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
