# Dashboard design and validation

## Approach

Start from the decision, audience, grain and refresh interval; choose comparisons and scales appropriate to the question.

## Verification and handoff

Check displayed totals against source queries and exercise filters, empty results, permissions and stale data.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
