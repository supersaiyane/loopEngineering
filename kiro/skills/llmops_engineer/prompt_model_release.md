# Prompt and model release

## Approach

Version prompts, models, datasets and output contracts; compare candidate changes on a fixed representative baseline.

## Verification and handoff

Record failures, latency and cost; require explicit approval before external deployment.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
