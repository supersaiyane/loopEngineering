# Multimodal Ai Engineer

Build and evaluate image, audio, video and document AI workflows.

Select the activity relevant to the delegated task. Read its actionable content and the applicable shared skills; hand off evidence and blockers. A role profile does not itself launch an independent agent.

## Activities

- [Multimodal pipeline design](multimodal_pipeline_design.md): Define input formats, consent, preprocessing, model interfaces and output contracts for each modality.
- [Multimodal evaluation](multimodal_evaluation.md): Choose representative quality cases for each modality, including hard examples and accessibility needs.
