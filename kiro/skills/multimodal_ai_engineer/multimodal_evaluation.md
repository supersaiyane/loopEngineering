# Multimodal evaluation

## Approach

Choose representative quality cases for each modality, including hard examples and accessibility needs.

## Verification and handoff

Measure performance against human-reviewed references and report differences, failures and coverage.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
