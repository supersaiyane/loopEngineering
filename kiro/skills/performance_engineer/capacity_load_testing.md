# Capacity and load testing

## Approach

Define concurrency, data size, failure criteria and safe test environment with system owners.

## Verification and handoff

Measure saturation, errors and recovery; do not run disruptive load against a shared or production service without authorization.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
