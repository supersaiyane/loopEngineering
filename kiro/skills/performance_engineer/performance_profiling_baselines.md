# Performance profiling and baselines

## Approach

Establish a representative workload, baseline, measurement environment and target before optimizing.

## Verification and handoff

Profile the bottleneck and compare equivalent runs; report distributions and measurement uncertainty.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
