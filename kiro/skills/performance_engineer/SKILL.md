# Performance Engineer

Measure and improve software performance and capacity.

Select the activity relevant to the delegated task. Read its actionable content and the applicable shared skills; hand off evidence and blockers. A role profile does not itself launch an independent agent.

## Activities

- [Performance profiling and baselines](performance_profiling_baselines.md): Establish a representative workload, baseline, measurement environment and target before optimizing.
- [Capacity and load testing](capacity_load_testing.md): Define concurrency, data size, failure criteria and safe test environment with system owners.
