# Inclusive low-resource UX

## Approach

Design age-appropriate interfaces only where the audience requires them; cover keyboard use, clear states and constrained devices.

## Verification and handoff

Measure representative journeys and combine automated checks with human accessibility review.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
