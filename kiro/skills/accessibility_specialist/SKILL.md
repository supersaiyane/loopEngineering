# Accessibility Specialist

Evaluate accessibility through automated and informed manual review.

Select the activity relevant to the delegated task. Read its actionable content and the applicable shared skills; hand off evidence and blockers. A role profile does not itself launch an independent agent.

## Activities

- [Manual accessibility review](manual_accessibility_review.md): Test keyboard operation, focus, semantics, names, contrast and screen-reader workflows on representative journeys.
- [Inclusive acceptance criteria](inclusive_acceptance_criteria.md): Write testable accessibility criteria for states, inputs, errors and responsive behavior.
