# Inclusive acceptance criteria

## Approach

Write testable accessibility criteria for states, inputs, errors and responsive behavior.

## Verification and handoff

Include manual review and users with relevant needs when feasible; distinguish target from verified conformance.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
