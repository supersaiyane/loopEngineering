# Curriculum and objectives

## Approach

Connect each learning objective to prerequisite knowledge, a suitable activity and a measurable outcome.

## Verification and handoff

Identify curriculum source and age assumptions; involve qualified educators for subject accuracy.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
