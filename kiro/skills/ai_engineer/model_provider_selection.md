# Model and provider selection

## Approach

Define task quality, latency, budget, data handling and availability needs; compare only verified current provider capabilities.

## Verification and handoff

Evaluate alternatives on the same representative dataset and record fallbacks, costs and unknowns.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
