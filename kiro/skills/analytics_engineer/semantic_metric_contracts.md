# Semantic metrics and contracts

## Approach

Define numerator, denominator, grain, dimensions, exclusions, ownership and freshness before implementing a metric.

## Verification and handoff

Version interfaces and compare semantic-layer results to a source query; identify incompatible downstream consumers.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
