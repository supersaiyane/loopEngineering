# Experiment registry and reproducibility

## Approach

Version training data, code, dependencies, configuration, metrics and candidate artifacts.

## Verification and handoff

Reproduce a run on an isolated sample and document untracked inputs and nondeterminism.

Report the inputs, decisions, evidence, assumptions and blockers to the next role. Use existing project constraints and explicit authorization; do not invent an execution or external result.
